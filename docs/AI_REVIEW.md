# AI review (outside the app)

Use an AI assistant or agent to moderate notes instead of, or before, human reviewers. The app never calls an AI itself. You carry a file out and paste the AI's reply back in.

## Workflow

1. **Admin → AI review → Create export.**
   - Every *pending* note is exported (optionally only unassigned ones), split into files of 100–500 notes.
   - Each file is Markdown: the full instructions for the AI, then the notes as JSON.
   - Per note: `id`, `teacher`, `grade`, `chars`, `flags`, `text`. Class, submission, reviewer and timestamps are never exported.
2. **Give each file to the AI.** Attach it or paste it into a chat, or hand it to an agent. The AI replies with JSON only.
3. **Admin → AI review → paste the reply (or upload it) → Check.**
   - The preview counts approve / trash / unsure / skipped and lists every trash and unsure reason. Click an id to read the note.
   - Nothing has changed at this point.
4. **Apply.** Every applied change is written to the note's history and the audit log as `ai_import`:
   - **approve:** the note is approved.
   - **trash:** the note moves to Trash, with status reason `AI review: <reason>`. It can be restored.
   - **unsure:** the note stays pending, gets the flag **AI unsure** (find these on Notes → *Flagged*) and keeps the AI's reason.

Batches can be imported one at a time and in any order. They share one `exportId`.

## Safety rules (enforced by the server)

- Only notes that are **still pending and unchanged since the export** are touched. Anything a person reviewed or edited in between is skipped as "changed since export" or "already reviewed".
- Ids not in the export, duplicate ids and notes from voided submissions are skipped and listed.
- Re-importing the same reply is harmless.
- One reply can hold at most 500 decisions.
- Admin-only. Reviewers can't export or import.

## Exact reply format the AI must return

```json
{
  "format": "stjb-ai-review-v1",
  "exportId": "aix_…",
  "decisions": [
    { "id": "note_…", "decision": "approve", "reason": "" },
    { "id": "note_…", "decision": "trash", "reason": "Mocks the teacher's appearance" },
    { "id": "note_…", "decision": "unsure", "reason": "Mentions another student by name" }
  ]
}
```

- `format`: exactly `stjb-ai-review-v1`
- `exportId`: copied from the file
- `decision`: `approve`, `trash` or `unsure` (lower case)
- `reason`: at most 200 characters; required in practice for trash and unsure

Code fences or a sentence around the JSON are tolerated. Anything else is rejected with a message saying which field is wrong.

The instruction text is generated by `buildAiPrompt()` in `src/shared/ai-review.ts`. Edit it there if the council's moderation rules change.
